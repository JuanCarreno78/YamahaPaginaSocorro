# Recursos de tecnologías

Usa esta carpeta para almacenar logos o íconos locales de tecnologías Yamaha si más adelante decides dejar de usar SVG inline en el frontend.

Estructura sugerida:

```text
public/images/tecnologias/
├── blue-core.svg
├── abs.svg
├── fi.svg
├── full-led.svg
├── y-connect.svg
└── smart-key.svg
```
